KDOG'S PHOTOGRAPHY WEBSITE
===========================

This version is fully wired to an /images folder.

IMPORTANT
---------
There are intentionally NO JPG files included.
The website points to the filenames below. Until you add them, each image space
shows a coloured placeholder plus the exact filename you need to replace.

To add your photos:
1. Open the /images folder.
2. Export/copy your photos into that folder.
3. Rename each photo to match the relevant filename exactly.
4. Refresh the website. No HTML editing is required.
